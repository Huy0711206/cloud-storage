# CloudBox
Purpose: manage storage, plans and payments with real data.
Visual direction: minimal Modern SaaS, left-aligned content, no invented metrics.
Palette: primary #2563EB, canvas #F6F8FC, surface #FFFFFF, text #172033, secondary #647084, success #15803D. Semantic dark equivalents.
Type: locally served Plus Jakarta Sans Variable, Vietnamese subset. Body 14-16px, headings 24-30px, tabular figures.
Layout: 248px sidebar, 72px header, max 1280px content, 24-32px gutters. Mobile sheet below 768px. Spacing 4/8/12/16/24/32/48. Radius 8/12/16.
Motion: 150ms controls, 200ms dialogs, reduced-motion supported.
A11y: labeled fields, visible focus, skip link, 44px actions, named dialogs, native forms, error summary.
States: skeleton, pending submit, inline validation, empty orders, retry usage, error boundary.
Pages: home/pricing, auth, verification, dashboard/storage/plans/orders/settings, admin overview/users/orders/plans.
Integration: safe server bootstrap, existing POST routes/session, Nextcloud storage and VNPay sandbox redirects.
